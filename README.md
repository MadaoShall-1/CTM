# CTM

Research workspace for continuous-thought world models and UAV navigation.

- `Dreamer-master/`: Dreamer code with the UAV task adapter and smoke test.
- `her_mpdqn_reproduction/`: reproducible Direct/Relay UAV environments,
  P-DQN/MP-DQN/HER baselines, experiment tooling, and CT-WM trajectory export.

Generated training outputs and model checkpoints are intentionally excluded
from Git. See each subdirectory's README for setup and usage.
